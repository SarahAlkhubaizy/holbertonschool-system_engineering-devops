# Web Infrastructure Design

Whiteboard exercises on designing web infrastructures, as part of the Holberton School sysadmin/DevOps track.

## Learning objectives

- Draw a diagram covering a web stack and explain what each component does
- Explain system redundancy
- Know the acronyms: LAMP, SPOF, QPS

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-simple_web_stack` | One-server web infrastructure (Nginx, application server, code base, MySQL) reachable via `www.foobar.com` |

## Requirements

- All answers are written in English
- Each task includes a link to a screenshot/picture of the whiteboard diagram
- Tasks are reviewed manually and whiteboarded in front of a reviewer, without a computer or notes
